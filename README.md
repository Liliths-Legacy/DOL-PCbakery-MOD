# PC的面包坊
在峭壁街咖啡馆旁边增加了一个可租赁的商铺。<br>
PC可以在这里制作和贩卖烹饪品。经营流程带有rougelike要素，鼓励每次流程采用不同的贩卖策略。

✨v2.0.0更新：自本版本起，本模组的定位更改至为**大型生活扩展MOD**。<br>
除了面包坊的玩法扩展外，还会添加**其他场景、玩法、剧情、功能上的扩展**。<br>
这些功能并不一定围绕面包坊展开，但是为了方便起见，本MOD的名称仍然沿用“PC的面包坊”。<br>
面包坊的相关玩法也会持续更新，作为生活扩展中的一个部分。

## 内容详细
### 地点与玩法扩展
- 为峭壁街添加了一个PC可经营的小店；
- 根据随机BUFF与订单**自由搭配**烹饪品，提交套餐赚取更高的报酬；
- （*未来开发计划*）添加命名NPC的专属随机剧情；

### 原版厨房优化
- 添加了可选的厨房显示优化，将制作移至一级菜单，提供**更加便捷快速**的交互体验；

### 原材料获取扩展
- 添加了森林、草地、荒原三处随机的**打猎事件**，为猪肉、鸡肉、牛肉的获取增加来源；并配套了伊甸处的获取猎枪、猎物处理功能剧情；
- （v1.0更新）为原版的水果增加了**果树种植**，并在Alex农场的林地添加了的乔木/灌木种植区；添加了乔木/灌木种植区的配套升级项目；添加了配套的可重复收获逻辑；
- （v1.0更新）为新增的饮料制品添加了六种**新的作物**：葡萄、啤酒花、可可豆、咖啡豆、茶叶；
- （v1.0更新）添加了一个农具：**铲子**；可用来清除已种植的作物；

### 烹饪制品扩展
- （v1.0更新）添加了12种**全新的可制作饮品**，包括咖啡、茶类、酒类各四种；可在学校烹饪课获取食谱；

### 衣着系统优化
#### (v2.0更新) 原版衣着系统扩展：时装槽
✨“再也不用担心打扮得好好的衣服出门就被撕坏了！”
- 为原版的衣着系统增加了一个时装槽。
任何更换衣服的场景，都可以在“时装模式”与“装备模式”切换并分别调整二者的衣着 —— 「时装」影响模型显示；「装备」接管游戏玩法（遭遇战中的穿脱和防御、气温与保暖度、服装要求、浸湿与暴露等）；

#### (v2.0更新) 原版衣着系统扩展：整套购买
✨“再也不用担心预设套装丢配件而穿不齐了！”
- 为所有服装店接入了衣柜的套装编辑与交互，可以在商店一键着装，缺少的配件会从当前商店中自动补全。<br>
同时也支持商店中搭配好后一键保存为套装，解放在更衣室与商店之间跑来跑去的流程。

### (v2.0更新) 内置wiki攻略
✨“切屏出去上wiki/问贴吧大佬太麻烦，有更轮椅的方法吗？”
需要前置模组[DOLI（Degrees of Lewdity Intelligence）](https://github.com/ArsNativa/Degrees-of-Lewdity-Intelligence) 与 LLM API<br>
- 为DOLI的辅助助手增添了查询wiki（包含中英文站）的agent能力，可以直接在游戏内通过问答获得攻略。<br>
示例：“我还缺少哪些古董？” 、 “alex的农场如何入住？”、”行走的广告牌这个成就如何完成？”等等。
