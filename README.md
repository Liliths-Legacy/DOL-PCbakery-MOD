# PC的面包坊

v0.4.0

增加了面包坊外的厨房显示与交互优化，可在选项中开启/关闭替换。

在峭壁街咖啡馆旁边增加了一个可租赁的商铺。
PC可以在这里经营自己的面包店，制作和贩卖烹饪品。
经营流程带有rougelike要素，鼓励每次流程采用不同的贩卖策略。

## 内容
## 面包坊

可以在峭壁街租下一间门店，开自己的面包坊。
租金：每月 10,000 / 20,000 / 30,000 （每个档位每天可以招待的客户数量不同，待开发

## 厨房扩展
面包坊内的制作交互相比原版厨房进行了优化，旨在提供更好的制作与订单交付体验

## 游玩模式

每一局都大致是这样一个流程，带有一定的rougelike要素：

从三个候选订单中选择一个 -> 完成订单要求 -> 根据提交的食物&buff结算评分 -> 根据评分结算收入 -> 选择新buff -> ... 循环 直至关店时间，或者自行选择提前打烊

- 每天早上8:00-21:00之间都是可营业时间；这个时间段内任何时间都可以开始一局游戏
- 每局的buff都是独立的，开局的时候选择一个，之后每三个新订单选择一个，结束时清空
- 原料、食物储备全局共享，沿用原版的计数逻辑；现做只能用来提交当前订单，消耗原版的原料，但是不进入原版的食物库存。
- 每个食物的制作都需要花费一定的时间；在接取订单之后可以使用之前已经做好的，也可以当场现做，现做的会有一定的评分加成

### 订单要求

1. 包含某种原料类
2. 总共提交的食物数量类：总上限不可超过三个，在此基础上，订单可能要求一个/两个/三个
3. 种类组合类：游戏里一共有三种分类 - 甜品、菜肴、饮料；可能会要求提交的食物里包含有其中某几种
……

  1. 评分加成类：某种类型订单获得评分加成
