# PC的面包坊 · PCBakery

为 Degrees of Lewdity 添加一间可以租赁、经营的面包坊。前往峭壁街，从「面包坊出租告示」进入，租下店面后即可接单、制作食物并赚取收入。

## 下载与安装

1. 在 [最新 Release](https://github.com/Liliths-Legacy/DOL-PCbakery-MOD/releases/latest) 的 **Assets** 中下载 `pc-bakery.mod.zip`。
2. 在游戏的 ModLoader 模组管理界面导入此 ZIP，无需解压。
3. 启用 PCBakery，按加载器提示重新加载游戏，然后前往峭壁街。

GitHub 自动提供的 `Source code (zip)` / `Source code (tar.gz)` 是仓库源码快照；安装请使用 `pc-bakery.mod.zip`。

## 兼容版本

- MOD 版本：**0.3.3**。
- 游戏版本：**0.5.8.10**、**0.5.11.9**。
- ModLoader：依赖范围 `^2.100.0`。
- 此仓库仅提供 MOD，不包含游戏本体。

## 玩法

- 店面租金为 **£10,000 / 30 天**，一次付清，到期后手动续租。
- 营业时间为 **08:00—21:00**；21:00 后不再接取新订单，已接订单可以完成。
- 从三个候选订单中选择一个，用已解锁的食谱和已有库存完成要求，也可以消耗原料现场制作。
- 提交食物后按订单要求与本局增益结算收入；现场制作有评分加成。
- 开局选择一次营业增益，此后每完成三个订单再选一次；增益仅在本局有效。
- 可以暂停营业后回来继续；主动打烊后当天不能重新开局。
- 原料和库存沿用游戏数据；现做食物留在临时托盘中，不进入全局成品库存。

## 仓库内容

`boot.json`、`scripts/`、`styles/`、`game/` 是加载 MOD 所需的文件。开发框架、开发计划、测试文件和本地游戏预览不包含在此仓库中。
